# HuntFlow releases

Downloads used by HuntFlow's **Update now** button (NinjaTrader 8 add-on by Hunt4Trades).

HuntFlow is invite-only: it needs a personal access code from Hunt4Trades to run.

| Version | Build | File |
|---|---|---|
| 6.0 | S98 | HuntFlow-6.0.zip |

To install by hand: NinjaTrader > Tools > Remove NinjaScript Assembly > HuntFlow, restart, then Tools > Import > NinjaScript Add-On > the zip, and restart again.
